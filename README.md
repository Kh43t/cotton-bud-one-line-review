One line, at most 200 characters, reviewing the most boring everyday object: the cotton bud.

> The cotton bud cleans nothing: it just pushes the wax further in, then gets thrown away for doing exactly what you asked.

(121 characters.) The joke comes from how the object really behaves: a cotton bud is hired to clean your ear, and instead it pushes the wax further in — then gets thrown away for doing exactly what you asked. Its own dullness is the joke.

## Run it

```sh
node main.ts
```

The program writes the review to `/output/entry.txt` and self-checks it first: exactly one line, 1–200 characters, naming the cotton bud.
